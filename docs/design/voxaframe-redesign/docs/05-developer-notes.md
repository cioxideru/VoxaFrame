# VoxaFrame — заметки о поведении для разработчиков

Документ дополняет макеты: https://claude.ai/artifact/XMo2UvEjiRNxmZx5y29F8J. Токены и контракты компонентов — в дизайн-системе: https://claude.ai/artifact/17z8WXCD8FyUP7r1wp1qaN. Источник истины по поведению — `VoxaFrame-Functionality.ru.md`. Номера разделов ниже — оттуда.

## 1. Токены и темы

- **Цвета семантические.** В SwiftUI берите системные роли: `Color.primary`, `.secondary`, `Color(.systemBackground)`, `.secondarySystemBackground`, на macOS — AppKit-эквиваленты. Hex в макетах — fallback для HTML.
- **Акцент.** Настройка Accent Color: System + 10 цветов.
  - **Допущение:** «System» = фирменный коралл VoxaFrame (`AccentColor` в каталоге ассетов). Светлая тема — `#B83829`, тёмная — `#FF9988`.
  - Для мелкого текста используются затемнённые варианты, все ≥ 4,5 : 1. Таблица — в `04-a11y-hig-review.md`.
- **Тема.** System / Light / Dark — `preferredColorScheme`, при System — `nil`.
- **Liquid Glass.** Только `glassEffect` / системные bars, sheets, toolbar. Без стекла поверх стекла.
  - `Disable Liquid Glass` по описанию влияет на панель вкладок iOS 26+, а не на всё приложение.
  - Reduce Transparency обрабатывается системой. Для кастомных стеклянных элементов проверяйте `accessibilityReduceTransparency` → непрозрачный `elevated`.
- **Скрим под контролами на видео:** чёрный 72 %. Плашка длительности и Live — на скриме.
- **Движение:** fast 120 мс, standard 220 мс, layout 320 мс. При `accessibilityReduceMotion` — только прозрачность, без масштаба и parallax.

## 3. Поведение по областям

### Навигация
- Пять разделов: Главная, Поиск, Медиатека, Офлайн, Настройки.
  - На iPhone Поиск визуально справа, отдельной капсулой (роль search).
  - На Mac Поиск — пункт боковой панели и ⌘F.
- `Visible Sections` управляет чипами Главной, а не вкладками.
- Чипы Главной сбрасывают временный фильтр канала.

### Карточка и меню (§6)
- Нажатие открывает видео. Канал открывается по нажатию на название или командой «Открыть канал».
- Меню гостя: команды аккаунта ведут на вход. Not Interested и Don't Recommend Channel скрыты (P-Menus).
- Недоступное действие показывается выключенным, с причиной («Прямую трансляцию нельзя сохранить»).
- Меню Shorts — свой урезанный набор (§6). Не переносить все команды обычной карточки.

### Поиск (§7)
- Запуск результата заменяет текущую очередь видимым списком.
- Во время подтверждения фильтров результаты не перезапрашиваются: Apply применяет, Cancel откатывает.
- «Нет результатов» и «Ошибка» — разные экраны. Ошибка поиска — новый экран (A5).

### Плеер (§12)
- Качество: показывайте две величины — выбранную пользователем (Авто или ручное) и реально играющий формат.
  - Пример: «Авто · сейчас 1080p60 VP9».
  - Варианты, которых нет у ролика, не показываются, либо показываются выключенными с подписью «нет для этого видео» (I-Player).
- Удержание = 2× временно, предпочтение не перезаписывается.
- Перевод — четыре состояния: выключен → готовится (оценка времени приблизительная, «Смотреть без перевода») → играет → ошибка.
  - Ручной выбор аудиодорожки выключает принудительный перевод для ролика.
- Конец ролика: Loop → очередь → рекомендации (Shuffle / Autoplay).
  - Без Autoplay — последний кадр и «Смотреть снова».
  - Карточка «Далее через 5 с» — с отменой.
- Ошибка ролика не сбрасывает аккаунт. «Нужен вход» — отдельный текст с кнопкой входа.
- Мини-плеер: нажатие разворачивает, крестик останавливает. PiP — отдельное системное состояние.

### Shorts (§13)
- Собственные настройки: скорость (8 значений), язык аудио, Yandex, lively voices, исходный звук.
  - Обычные видео не меняются, и наоборот. Fit/Fill общий.
- Пока открыта панель Shorts, переход между роликами заблокирован.
- Конец: Loop → следующий → если его нет, остаться на завершённом. Autoplay обычных видео не влияет.
- На Mac видеослой не подключён (A7). На TV нет touch-ползунка.

### Офлайн (§14)
- Очередь загрузок и очередь просмотра — разные сущности и разные экраны. В текстах UI не называть загрузки «очередью» без уточнения.
- Задания одной записи группируются под названием видео: «Видео 1080p», «Аудио · Оригинал», «Перевод · RU».
- Шесть статусов: В очереди, Подготовка, Загрузка, Завершено, Ошибка, Отменено.
  - Действия строго по таблице §14.2.
  - Паузы нет; если нужна — B6.
- Баннер «Загрузки уступают сеть плееру» — информационный, не ошибка.
- Страница видео:
  - кнопка воспроизведения выключена при несовместимом сочетании дорожек, с объяснением;
  - пропавший файл → ошибка + «Скачать снова» (только при сети);
  - без подмены онлайн-потоком.
- Удаление трёх уровней — задание, видео, вся библиотека — всегда с подтверждением и перечнем последствий.
- HLS — только iPhone/iPad. На Mac и TV выбор ограничен прямыми файлами (P-Offline-Start, M-Offline, T-Settings).

### Настройки (§15–16)
- Токен Yandex: `SecureField`, хранение в Keychain; в UI только маска `••••••••`.
  - Токен никогда не выводится в уведомлениях, логах и демо-данных.
- Три области данных (P-Settings-2): аккаунт Google, это устройство, офлайн-файлы. Общей кнопки «очистить всё» нет.
- iCloud: подпись «Экспериментально…». Не показывать «Синхронизировано» и время синхронизации (§17).
- PIN защищает вход в настройки, а при закрытии настроек защита снова включается. На Mac это вход в окно Settings.

### Mac
- Плеер встроен в окно. Справа инспектор: «Далее», «Описание», «Комментарии».
- Закрытие инспектора или панели ≠ закрытие окна. ⌘W закрывает окно.
- Окно Settings — отдельная `Settings` scene.
- Ширина < 1000 pt: инспектор уходит под видео, затем сворачивается боковая панель. Минимальный размер окна не меняется без проверки.

### TV
- Back сначала закрывает меню или панель, затем возвращает на уровень выше. Фокус возвращается к исходному элементу.
- Удержание Select на карточке открывает меню и не запускает видео.
- На TV нет Share-меню и уведомления «Готово для офлайна»; статус загрузок виден в разделе Офлайн.

## 4. Допущения дизайна

1. Mac — нативный macOS (`SUPPORTS_MACCATALYST = NO`), все Mac-доски построены на этом.
2. «System» в Accent Color = фирменный коралл из `AccentColor`. Если в коде System = системный синий, коралл остаётся только брендом иконки.
3. Направление Apple 27 опирается на паттерны iOS/macOS 26 (Liquid Glass, вкладка-поиск, bottom accessory). На iOS 17–25 используются ближайшие стандартные компоненты, без имитации стекла.
4. Демо-контент вымышленный: каналы Field Notes, Studio North, Everyday Films, Night Walks, Sound Room, Frame by Frame; пользователь «Анна»; адреса `*.example`.
5. Числа в макетах (размеры офлайн-файлов, количество видео, проценты) иллюстративны.
6. Блок «Продолжить просмотр» на iPad/Mac/TV — новое предложение (B7), а не текущая лента.

## 5. Что не входит в основной объём

- **Download to Gallery и его Live Activity** — флаг `ENABLE_DOWNLOADS`, доска S-Optional, серые метки.
- **Live Activity для «Офлайн-видео»** — новое предложение C1.
- **Функции, которых нет в продукте** (§21) — не рисовались: редактор плейлистов, комментирование, Wi-Fi-only, Face ID для PIN, несколько аккаунтов, веб-плеер.
