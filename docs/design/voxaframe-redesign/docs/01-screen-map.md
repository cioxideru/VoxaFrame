## Экраны

### Обзор и компоненты
- **Main** — карта экранов, легенда меток, 11 сценариев с досками.
- **C-Foundations** — цвет и акценты, типографика iOS/Mac/TV, материалы, отступы, скругления, движение.
- **C-Controls** — кнопки, чипы, переключатели, поля, сегменты, состояния hover/focus/disabled.
- **C-Navigation** — панели вкладок, боковые панели, вкладки TV.
- **C-Cards** — сеточная, компактная и Short-карточки; Live, премьера, прогресс, Watch Later, без обложки, DeArrow.
- **C-Player** — элементы плеера, шкала с главами и SponsorBlock, жестовые индикаторы, Stats for Nerds, конечные заставки.
- **C-Rows** — строки заданий, офлайн-вариантов, настроек, RSS и очереди.
- **C-Feedback** — состояния, меню, диалоги, подтверждения, PIN.

### iPhone

**Главная**
- P-Home — светлая и тёмная.
- P-Home-States — загрузка, гость, подгрузка и конец источника, ошибка с сохранённой частью, всё скрыто фильтрами.

**Карточки и каналы**
- P-Menus — меню карточки для аккаунта и для гостя, недоступные действия.
- P-Channel — страница канала All/Shorts, подписка в процессе, отписка с подтверждением, список каналов.

**Поиск**
- P-Search — история, подсказки, результаты.
- P-Search-More — панель фильтров, метки, нет результатов, ошибка.

**Плеер**
- P-Player — портрет.
- P-Player-Landscape — горизонтальная ориентация.
- P-Player-Panels — качество (выбрано ≠ играет), скорость, субтитры, таймер.
- P-Player-Translation — аудиодорожки и четыре состояния перевода Yandex.
- P-Player-More — действия, описание с отметками времени, комментарии.
- P-Player-States — буферизация, ошибка ролика, конец и автопереход, только аудио.

**Shorts и свёрнутый просмотр**
- P-Shorts.
- P-Mini — мини-плеер и PiP.

**Медиатека**
- P-Library — история (устройство и аккаунт), плейлисты, RSS.
- P-Queue — очередь, плейлист, выбор плейлиста.
- P-RSS — добавление ленты и управление лентами.

**Офлайн**
- P-Offline — библиотека, задания, все статусы.
- P-Offline-Start — выбор составляющих.
- P-Offline-Item — сохранённое видео, удаление, ошибка хранения.

**Настройки, вход, доступность**
- P-Settings и P-Settings-2 — все блоки разделов 15–16.
- P-SignIn-PIN — вход по коду и QR, истёкший код, ошибка; PIN.
- P-Accessibility — крупный текст AX5, длинные EN-подписи, Reduce Transparency + Increase Contrast, порядок VoiceOver.

### iPad
- I-Home-Landscape — широкое окно, боковая панель.
- I-Home-Portrait — портретная ориентация.
- I-Narrow — узкое окно, 600 pt.
- I-Player — плеер с боковой панелью параметров.
- I-Search — поиск и фильтры в поповере.
- I-Offline — офлайн-библиотека.

### Mac (нативный macOS)
- M-Home — Главная.
- M-Player — плеер в окне, инспектор, клавиатура (предложение).
- M-Narrow — окно уже 1000 pt.
- M-Offline — офлайн-библиотека.
- M-Search — поиск.
- M-Settings — отдельное окно настроек.

### Apple TV
- T-Home — Главная.
- T-Player — плеер.
- T-Player-Menu — аудио и перевод.
- T-SignIn — вход по QR.
- T-Shorts — Shorts.
- T-Settings — настройки, PIN, About с QR, офлайн на TV.

### Интерактивные прототипы
- **X-Search** — гость → поиск → подсказка → фильтры → демо «нет результатов»/«ошибка» → канал → локальная подписка → отписка → плеер.
- **X-Watch** — карточка → плеер → качество → скорость → аудио/перевод (готовится → играет/ошибка, «Смотреть без перевода») → свернуть в мини-плеер → закрыть.
- **X-Shorts** — переход вверх/вниз кнопками, своя скорость (8 значений) и перевод, конец списка, ошибка подгрузки с повтором.
- **X-Offline** — загрузка вариантов → выбор → задания с прогрессом → ошибка перевода и повтор → библиотека → режим без сети → воспроизведение локальных файлов → удаление дорожки или видео с подтверждением.

### Системные поверхности
- **S-Surfaces** — расширение «Поделиться», виджет «Главная», экран блокировки, Spotlight, Команды и Siri.
- **S-Optional** — Download to Gallery и его Live Activity (только спецсборка); Live Activity для «Офлайн-видео» (новое предложение).
