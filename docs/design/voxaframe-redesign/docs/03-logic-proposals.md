# VoxaFrame — предложения, требующие изменения логики

На макетах эти места отмечены **фиолетовой меткой**. Сам макет не делает их работающими: каждое предложение нужно согласовать и реализовать в коде.

Пункты A — исправления ограничений, которые раздел 21 функционального описания просит не выдавать за готовое. Пункты B — улучшения интерфейса, которым нужны новые данные или поведение. Пункты C — новые функции.

## A. Исправления текущих ограничений

| # | Предложение | Сейчас | Нужно в логике | Доски |
|---|---|---|---|---|
| A1 | **Постоянный вход в Очередь.** Сегмент «Очередь» в Медиатеке; пункт боковой панели на iPad и Mac | Вход зависит от состояния экранов Playlists | Источник данных очереди независим от загрузки плейлистов; маршрут `queue` | P-Library, I-Home-Landscape, M-Home, C-Navigation |
| A2 | **Play Next вставляет после текущего видео** | Добавляет в конец очереди | Вычислять позицию после играющего элемента. Если ничего не играет — первым | P-Menus, Main |
| A3 | **Редактор очереди:** перестановка и удаление строки, кнопка «Изменить» | Операции есть в хранилище, UI не подключён | Подключить reorder/remove, обновлять индекс текущего элемента; VoiceOver-действия «Переместить выше/ниже» | P-Queue, I-Player |
| A4 | **Гостевая локальная история в Медиатеке** | History/Playlists в Library без входа закрыты приглашением войти | Library → History показывает локальные записи гостю; Playlists остаётся с приглашением | P-Library |
| A5 | **Экран ошибки поиска** с повтором, отдельный от «нет результатов» | Ошибка хранится в модели без экрана | Отдавать состояние ошибки во view; повтор того же запроса с теми же фильтрами | P-Search-More, X-Search |
| A6 | **Маршруты для результатов «канал» и «плейлист»**, одинаковые на всех платформах | Не подтверждены, особенно на Mac | Канал → страница канала; плейлист → экран плейлиста; на Mac — в области содержимого | M-Search |

| A10 | **Паритет RSS и SponsorBlock на платформах.** Добавление и управление RSS на Mac/TV через меню строки; добавление канала в исключения SponsorBlock из меню канала или плеера | Mac/TV без равного набора; добавления в исключения нет | Действия в меню; новая операция «Исключить канал» | P-RSS, P-Settings-2 |
| A11 | **Ошибка одной RSS-ленты** с повтором при остальных рабочих | Ошибки загрузки не везде показаны | Состояние ошибки для каждого источника | P-Library |
| A12 | **Честная формулировка iCloud** («экспериментально», без времени синхронизации) — до завершения механизма | Переключатель есть, полного цикла нет | Только текст; после завершения синхронизации пересмотреть | P-Settings-2 |

## Не предлагается

Эти функции нет в продукте, и они остались вне макетов:

- создание, переименование и удаление плейлистов YouTube;
- написание, ответы и лайки комментариев;
- лайки и комментарии в Shorts;
- Wi-Fi only, расписание и автоскачивание подписок;
- Face ID и восстановление PIN;
- несколько аккаунтов одновременно;
- переключатель «нативный/веб-плеер».
