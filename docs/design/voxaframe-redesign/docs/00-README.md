## Как устроен холст

Страницы: **Обзор** → **Компоненты** → **iPhone** → **iPad** → **Mac** → **Apple TV** → **Прототип** → **Системные поверхности**.

Префиксы досок: `C-` компоненты, `P-` iPhone, `I-` iPad, `M-` нативный macOS, `T-` tvOS, `X-` интерактивные прототипы, `S-` системные и условные поверхности.

У большинства досок есть настройки (Tweaks): тема `light/dark`, акцент (11 значений), прозрачность `glass/reduced`. Через них проверяются обе темы, пользовательский акцент и Reduce Transparency на одном и том же макете.

## Условные обозначения на макетах

- **Коралловая метка** — новое решение интерфейса. Поведение то же, меняется только подача.
- **Фиолетовая метка** — нужна доработка логики приложения. Полный список в `03-logic-proposals.md`.
- **Серая метка** — условный объём, только для специальной сборки (`ENABLE_DOWNLOADS`).

## Ключевые решения

1. **Mac — нативное macOS-приложение**, не Catalyst. Окно разделено на боковую панель, содержимое и инспектор; плеер встроен в окно. Настройки открываются отдельным окном Settings (⌘,).
2. **iPhone/iPad (Apple 27).**
   - Плавающая панель вкладок Liquid Glass, Поиск — отдельная вкладка справа.
   - Мини-плеер — аксессуар над панелью вкладок.
   - На iPad в широком окне используется адаптивная боковая панель.
3. **Apple TV.**
   - Верхние вкладки; фокус показывается подъёмом и белой подложкой.
   - Всё, что на телефоне делается свайпом, доступно отдельной кнопкой.
   - QR и код входа читаются с расстояния.
4. **Стекло только в слое навигации и управления**, без стекла поверх стекла. При Reduce Transparency стекло заменяется непрозрачными поверхностями.
5. **Разделение данных везде, где оно влияет на действия:**
   - очередь просмотра ≠ очередь загрузок;
   - история поиска ≠ история просмотров;
   - данные устройства ≠ данные Google ≠ офлайн-файлы.
6. **Контент вымышленный.** Реальных аккаунтов, e-mail и токенов нет; токен Yandex везде показан только маской.

## Что использовалось для Apple HIG

Навык `apple-hig` в этой среде **недоступен**. Использовались официальные Apple Human Interface Guidelines и материалы WWDC25 о Liquid Glass. Направление Apple 27 построено на принципах Liquid Glass, введённых в iOS/macOS 26. Изменения, специфичные для 27-й версии, нужно сверить с текущим HIG при реализации. Подробности в `04-a11y-hig-review.md`.
