Плеер

Качество (выбрано ≠ играет), скорость, аудио, перевод Yandex, субтитры, главы, SponsorBlock, таймер сна, Fit/Fill, только аудио, описание, комментарии, статистика

Shorts

Вертикальный плеер, свой набор: скорость, язык аудио, перевод, lively voices, исходный звук. Mac — видеослой не подключён

Свёрнутый просмотр

Мини-плеер — аксессуар над панелью вкладок (iPhone/iPad). PiP — системное окно. Закрытие одного не разворачивает другое

Вход и защита

Гость по умолчанию. Вход по коду и QR, таймер, истёкший код. PIN защищает только вход в настройки

Сценарии и где их смотреть

1. Гость находит видео, открывает канал, локальная подписка — P-Search, P-Channel, X-Search

2. Вход по коду, подписки, Watch Later — P-SignIn-PIN, P-Menus, T-SignIn

3. Поиск с фильтрами; пусто и ошибка различимы — P-Search-More, X-Search, I-Search

4. Качество, скорость, аудио, субтитры без потери просмотра — P-Player-Panels, X-Watch

5. Перевод: ожидание, включение, отказ — P-Player-Translation, X-Watch, T-Player-Menu

6. Свернуть и развернуть ролик, закрытие останавливает — P-Mini, X-Watch

7. Shorts: свои скорость и язык — P-Shorts, X-Shorts, T-Shorts

8. Выбор составляющих, задания, повтор, запуск без сети — P-Offline-Start, P-Offline, X-Offline

9. Удаление варианта, видео, всей библиотеки — P-Offline-Item, C-Feedback

10. Вид, история, SponsorBlock, PIN — P-Settings-2, M-Settings, T-Settings

11. Тот же путь с пульта и в окне Mac — T-Home, T-Player, M-Home, M-Narrow
