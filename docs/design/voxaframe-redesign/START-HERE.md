# VoxaFrame redesign — вход для Claude Code

Новый интерфейс VoxaFrame (iPhone, iPad, нативный macOS, Apple TV, Apple 27 / Liquid Glass). Задача — реализовать его в SwiftUI в этом репозитории.

## Что читать по порядку

1. `docs/00-README.md` — решения и условные обозначения.
2. `docs/VoxaFrame-Functionality.ru.md` — источник истины по поведению. При расхождении с макетом прав он.
3. `docs/01-screen-map.md` — экраны, платформы и сценарии.
4. `docs/05-developer-notes.md` — компоненты → SwiftUI, поведение, допущения.
5. `docs/03-logic-proposals.md` — что требует изменения логики. Без согласования не делать.
6. `docs/02-feature-coverage.md` и `docs/04-a11y-hig-review.md` — для проверки.

## Макеты

`mockups/*.dc.html` — исходники досок. Читайте как HTML-разметку: тексты, структура, состояния. Отдельно в браузере они не рендерятся, им нужен рантайм холста.

- Стили и токены — `mockups/vf.css`.
- Список досок и подписи — `mockups/canvas.json`.

Префиксы досок:

| Префикс | Что |
|---|---|
| `C-` | компоненты |
| `P-` | iPhone |
| `I-` | iPad |
| `M-` | Mac |
| `T-` | TV |
| `X-` | прототипы с логикой состояний |
| `S-` | системные поверхности |

Метки в разметке:

| Класс | Значение |
|---|---|
| `class="prop"` | новое UI-решение |
| `prop logic` | нужна доработка логики |
| `prop cond` | только спецсборка `ENABLE_DOWNLOADS` |

## Дизайн-система

`design-system/tokens.json` содержит цвета light/dark, типографику iOS/Mac/TV, отступы, радиусы и размеры. Контракты компонентов лежат в `design-system/components/*/README.md`.

## Правила

- Mac — нативный macOS, не Catalyst.
- Цвета берутся из системных семантических ролей, hex — только fallback.
- Liquid Glass только в слое навигации и управления. При Reduce Transparency — непрозрачные поверхности.
- Токен Yandex никогда не выводится, только маска.
- Мини-плеер, PiP и HLS-загрузку на Mac/TV не добавлять.
